# X

Argus ingests X account and search data through an FxEmbed endpoint that you deploy and control. FxEmbed runs as a Cloudflare Worker; Argus does not rely on a public third-party FxTwitter instance.

Configure the source endpoint to the Worker’s `/api` realm. Supply the required Cloudflare credentials through the onboarding secret flow, never in committed configuration.
