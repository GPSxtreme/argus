# Web

Argus supports three Web source modes:

- **Direct URLs** fetch a specific public page.
- **Feeds** ingest RSS or Atom updates.
- **Managed SearXNG queries** discover public pages through the private SearXNG service managed by Argus.

Direct URLs and feeds are explicit targets. Queries are discovery inputs and require managed SearXNG; none of these modes bypass site access controls.
