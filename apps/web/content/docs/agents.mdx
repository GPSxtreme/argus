# Agents

Argus publishes machine-readable documentation at `/llms.txt`, `/llms-full.txt`, and `/docs/<path>.md`. Each interface is generated from these MDX documents.

The [Agent Skill](/skill) provides portable setup, diagnosis, repair, and update guidance. It uses stable CLI contracts, keeps secrets out of chat, and requires approval at external-change boundaries.
